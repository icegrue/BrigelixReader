# Brigelix Reader

Brigelix Reader 是一款 RSS 阅读客户端，帮助你集中订阅、整理和阅读感兴趣的内容。

本仓库用于发布官方安装包、更新日志和安装说明，不包含客户端源代码。

## 功能

- RSS 订阅与文章阅读
- 订阅源分类与管理
- 阅读状态、收藏与稍后读
- 本地缓存与离线阅读
- 登录后的云端同步
- 浅色、深色及跟随系统主题

## Android 安装

1. 下载最新正式版 APK。
2. 下载完成后，点击 APK 文件开始安装。
3. 如果系统提示不允许此来源安装应用，请按系统提示，为当前使用的浏览器或文件管理器授予安装权限。
4. 完成安装后，打开 Brigelix Reader。

安装完成后，可以撤销该来源的安装权限。

如果系统明确提示应用存在安全风险，请保留提示截图并联系我们。

## 更新

客户端发现新版本后，会提供更新提示；你也可以在「关于」中检查更新，或访问本仓库的 Releases 页面。

下载新版 APK 后直接安装，正常覆盖升级无需卸载旧版本。

如果提示签名冲突或无法覆盖安装，请先确认已安装版本的来源，并联系我们。请勿为解决安装问题直接卸载，以免丢失尚未同步的本地数据。
